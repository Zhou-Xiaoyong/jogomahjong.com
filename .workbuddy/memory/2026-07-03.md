## 第七轮：消除音效修复
- **问题**：用户反馈消除音效完全听不到
- **根因1**：`playSound()` 调用 `initAudio()` → `audioCtx.resume()` 是异步的，但没等 resume 完成就调用了 `synthMatch`，AudioContext 可能还处于 suspended 状态
- **根因2**：ConvolverNode 混响节点创建与 buffer 赋值在部分浏览器上静默失败，导致整个音频链路中断
- **修复**：
  - 新增 `masterGain` 总音量控制节点（0.8），所有声音统一经过它
  - `playSound` 改为检测 AudioContext.state，若未 running 则等 `resume()` promise 完成后再播放
  - 去掉 ConvolverNode，改用 noise → bandpass → highpass → envelope 简化链路
  - 调整滤波参数：中心频率 1400-2000Hz（提升了200Hz），Q=6-9（降低了Q让频带更宽、能量更足）
  - 持续时间略微延长至 0.10~0.14s，stop 加上 0.02s 余量确保完整播放
  - 声音文件改为 AudioContext 创建后才懒加载，避免预加载时创建孤立上下文
